# Daiyu2：当前设计方向

## 已明确的用户要求

- 《待雨》美术改为 2D 风格，保留斜向透视俯视，不切为正俯视或等距正交。
- 直接朝可游玩版本开发，不先制作独立风格试验，压缩验证周期。
- 选项确认：2.5D 承载、清爽卡通、固定方向透视相机，保留平移缩放。
- 复用旧核心与玩家流程，允许粗粒度水模型；新旧存档隔离，不要求旧 v4 直接兼容。
- 首版 Windows 完整基础流程：菜单、随机新局、简短教程、引水、催雨、生态反馈、暂停返回和存读档。

## 玩法参考与保护方向

旧《待雨》的有限水资源、引水、当地大气催雨、生态演化和随实际水况变化的视野作为复用参考。目标是让玩家能看懂水往哪里去，并看到调水对土地和生态的后果。

核心与玩家流程选择性复用，水模型允许简化；旧工程与真实玩家数据保持原样。实现状态和执行授权不在本页维护。

## 已选方案与待开工计划

使用简化三维地势承载二维卡通表现，以固定相机保证可读性；以有限账本与粗粒度转移替代精细开河几何依赖。细节和分批范围见 [风格方案](design/oblique-2d-playable.md) 和 [M1 计划](plans/tasks/M1-01_oblique_2d_playable.md)。

当前批准与实施状态只维护在 [当前阶段](plans/current_milestone.md)。

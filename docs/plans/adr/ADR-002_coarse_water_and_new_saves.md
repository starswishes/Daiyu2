# ADR-002：粗粒度水模型与独立新档

状态：**ACCEPTED（方向）**。用户选项明确允许水模型简化，要求有限水量/容量/引水/生态规则保留，新旧档隔离，不承诺读取旧 v4。当前开工授权与执行证据只查 [当前阶段](../current_milestone.md)。

## 背景

旧参考工程的精细开河几何、库存三角重分区与表现刷新是已记录的性能风险。Daiyu2 尚无游戏模块；直接迁入整套精细链路会将旧负担带入新工程，并限制首版可操作性。

## 决策

- 选择性复用账本、生成与生态/天气规则，不要求旧几何/模拟逐值等价。
- 新世界采用静态地势/邻接、地块/河段/节点级有限账户和容量约束的粗转移，规划只启用连接；实际库存只由账本转移。
- 显示与交互读取新世界的真实结果；旧 `RiverWorld` 不作为后台第二模拟世界。
- 新模型有独立版本化快照与玩家数据位置，包含完整权威状态及时间/速率余量；不自动寻找旧 v4 文件，不改写旧档。
- 完整基础流程仍需保存/恢复，模型简化不等于删掉教程、菜单或存档功能。

## 权衡

不保留精细岸坎/连续几何溢流/真实开河切地形；水路与容量需用粗模型定义明确的近似。旧 v4 存档导入器后置，不作为首版前提。优先保证有限水量、方向/连通、接收限制和可读的生态后果。

## 稳定条件

实现并通过工作流中的粗模型与保存恢复定向检查后，将对应技术契约转为 `STABLE`。本 ADR 记录方向决定，不作为模型实现或测试结果的证据。

# ADR-001：Daiyu2 以 2.5D 承载斜向透视的 2D 风格

状态：**ACCEPTED（方向）**。用户已通过选项确认 2.5D、清爽卡通、固定方向透视。当前开工授权与执行证据只查 [current_milestone.md](../current_milestone.md)。

## 背景

用户要求美术转为 2D，同时保留斜向透视并尽快交付可玩版，指定在 Daiyu2 工作。Daiyu2 当前只有模板场景/配置；旧参考游戏有三维地形、透视相机、独立纯模拟程序集和玩家流程，历史性能记录仍有表现与开河热点。

## 决策

复用必要核心与玩家流程，在 Daiyu2 建立简化三维地势，以二维景物、清爽卡通色块和轻量水体实现 2D 观感；固定方向真透视，保留平移缩放，玩家/菜单均不自动旋转。保持单一运行宿主。水模型简化与独立新档见 [ADR-002](ADR-002_coarse_water_and_new_saves.md)，覆盖原提案里保留 v4/旧模型的限制。

## 备选与权衡

- 纯二维等距/正交：素材组织简单，但不符合用户要求的真实透视。
- 整张平面地图倾斜：迁移较快，但高差和坡面表达弱，复杂地貌/拾取容易失配。
- 全景多方向预渲染：可形成精致画面，但资源制作与旋转成本不适合本次周期。
- 已选路线：固定视角降低插片多方向资源和遮挡成本，代价是玩家不能旋转避障；需在布局/淡出上保证水路可操作。粗模型处理旧精细几何依赖，透明绘制/批次仍需控制，不因采用 2D 就假定性能达标。

## 稳定条件

代码实际完成并通过工作流对应检查后，更新技术规范对应契约为 `STABLE`。方向选择、开工批准、实现与运行证据分别记录。
